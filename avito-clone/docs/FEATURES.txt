=====================================================================================
  АВИТО-КЛОН — ПОЛНЫЙ СПИСОК ВОЗМОЖНОСТЕЙ САЙТА
=====================================================================================

Доска объявлений (классифайд) в стиле Авито. Монолитное приложение: PHP 8.2+ (ООП) +
PostgreSQL 16, чистые HTML/CSS/JS без фреймворков, свой WebSocket-сервер для чата.
Запускается в Docker; на боевом сервере — за Caddy или за nginx на хосте (HTTPS).

Адреса страниц (после запуска):
  /                       главная: лента объявлений
  /ad.php?id=N            страница объявления
  /create-ad.php          создание / редактирование объявления
  /my-ads.php             мои объявления
  /ad-stats.php?id=N      статистика объявления
  /favorites.php          избранное
  /chat.php               сообщения (чат) и звонки
  /profile.php            профиль и настройки
  /seller.php?id=N        публичный профиль продавца
  /login.php              вход
  /register.php           регистрация
  /privacy.php            политика обработки персональных данных
  /terms.php              пользовательское соглашение
  /admin.php              админ-панель
  /robots.txt, /sitemap.xml   для поисковиков (формируются автоматически)

1. ДЛЯ ЛЮБОГО ПОСЕТИТЕЛЯ (без входа)
=====================================================================================

Лента объявлений
  - Карточки в сетке (4 / 3 / 2 колонки, на телефоне — горизонтальные карточки
    «фото слева, текст справа»), кнопка «Показать ещё», скелетоны при загрузке.
  - На карточке: фото, цена, заголовок, строка характеристик (например
    «Toyota · 2018 · 64 000 км»), город, дата, значок «Хит», число фото, значок
    видео, сердечко «в избранное».
  - Девять категорий с линейными значками: Транспорт, Недвижимость, Электроника,
    Одежда, Работа, Услуги, Животные, Для дома, Спорт и хобби. Полоса категорий
    под шапкой.

Поиск и фильтры
  - Живой поиск в шапке (результаты обновляются по мере ввода, с задержкой 300 мс).
  - Фильтры: город, категория, цена «от / до», сортировка (по дате, цена по
    возрастанию, цена по убыванию).
  - Фильтры по характеристикам выбранной категории (например марка и год для
    авто). Состояние фильтров хранится в адресе страницы, ссылкой можно делиться.
  - На телефоне фильтры открываются нижней шторкой.

Город «как на Авито»
  - При первом заходе сайт предлагает определить город: браузер запрашивает
    геолокацию (кнопка «Определить»), сервер превращает координаты в город.
  - Кнопка города в шапке открывает окно выбора: «Определить автоматически»,
    поиск по названию, «Все города», список популярных городов.
  - Выбранный город запоминается (в cookie и, если вы вошли, в профиле) и
    автоматически подставляется в фильтр ленты.
  - Геолокация работает только по https:// и только с разрешения пользователя.
    Если отказали или недоступно — город выбирается вручную.

Страница объявления
  - Галерея: стрелки, миниатюры, свайп на телефоне, счётчик «1 / N», полноэкранный
    просмотр фото. Видеообзор (если есть) — последний слайд галереи.
  - Блок характеристик, описание, город, дата публикации, число просмотров.
  - «Показать телефон» и/или «Написать сообщение» — в зависимости от способа связи,
    который выбрал автор; удобное время для связи.
  - «Поделиться», сердечко «в избранное».
  - Карточка продавца: имя, аватар, рейтинг и число отзывов, «на сайте с…», ссылка
    на публичный профиль.
  - Блок «Похожие объявления», хлебные крошки.
  - Корректные превью ссылок (Open Graph) с главным фото объявления.

Публичный профиль продавца
  - Аватар, «о себе», рейтинг, число отзывов, активные объявления продавца,
    вкладка «Отзывы».

Оформление
  - Светлая и тёмная темы. Переключатель в шапке; выбор запоминается, без выбора
    берётся системная тема, без «мигания» при загрузке.
  - Шрифт Montserrat (хранится на сервере), сдержанная сине-графитовая палитра,
    линейные SVG-иконки вместо эмодзи, собственный логотип, favicon.ico/svg,
    иконки для телефона (apple-touch-icon, 192/512), манифест сайта.
  - Адаптив от 360 px до широких мониторов; на телефоне — нижняя навигация
    (Главная, Избранное, «+», Чаты, Профиль).
  - Ссылка «Перейти к содержимому» для клавиатурной навигации.
  - Своя страница «404 — ничего не найдено».

2. РЕГИСТРАЦИЯ И ВХОД
=====================================================================================

Способы входа
  - Email + пароль (регистрация: имя, email, телефон по желанию, пароль).
  - Вход через Яндекс.
  - Вход через Google.
    (OAuth 2.0 с PKCE; кнопка провайдера появляется, когда для него заданы ключи
    в .env. Ключи вводятся скриптом bin/setup-oauth.sh, в чат и в код не попадают.)

Согласие с политикой
  - При регистрации и при ЛЮБОМ входе (email, Яндекс, Google) нужно поставить
    галочку согласия с Политикой обработки персональных данных и Пользовательским
    соглашением. Без галочки сервер вход и регистрацию не пропустит.
  - В профиле пользователя сохраняется время и версия принятого согласия.
  - Если администратор изменит текст документа, версия согласия вырастет и
    пользователям придётся принять документ заново.

Безопасность аккаунта
  - Пароли хранятся только в виде хеша. Аккаунты, созданные через Яндекс/Google,
    паролей не имеют.
  - Аккаунт, созданный по email, не «захватывается» входом через соцсеть с такой
    же почтой: привязать соцсеть можно только из профиля.
  - Сессии HttpOnly, защита CSRF на всех POST-запросах.

3. ДЛЯ ЗАРЕГИСТРИРОВАННОГО ПОЛЬЗОВАТЕЛЯ
=====================================================================================

Создание и редактирование объявления
  - Поля: заголовок, категория, цена (0 — «отдаю бесплатно»), город, описание.
  - Характеристики под выбранную категорию (поля появляются сами):
      авто — марка, модель, год, пробег, коробка, топливо, тип кузова;
      электроника — тип, бренд, состояние, гарантия, память и т. д.;
      недвижимость, одежда, работа, услуги, животные, для дома, спорт — свои поля.
    Есть обязательные и необязательные поля; цифровые поля проверяются по диапазону.
  - Город: подсказки при вводе (около 300 городов России плюс города из
    существующих объявлений), кнопка «Определить автоматически».
  - Предпочтительный способ связи:
      * «Звонок и сообщения» — покупатель выберет сам;
      * «Только сообщения» — телефон скрыт, общение в чате на сайте;
      * «Только звонок» — чат для этого объявления выключен.
    Плюс необязательное «удобное время для связи» (например «с 9 до 21 по Москве»).
    Если телефон в профиле не указан, вариант «Только звонок» недоступен.
  - Фотографии: до 10 штук, перетаскиванием или выбором файлов, первое фото —
    главное, JPG/PNG/WEBP/GIF до 5 МБ каждое.
  - Видеообзор (необязательно): ОТДЕЛЬНЫЙ ПУНКТ В САМОМ КОНЦЕ ФОРМЫ, ПОСЛЕ ФОТО.
    MP4, MOV или WebM до 50 МБ и до 3 минут; индикатор загрузки, предпросмотр,
    можно заменить или удалить.
  - Проверка полей прямо в форме, счётчики символов, форматирование цены.
  - После создания и после любого редактирования объявление уходит на модерацию.

Мои объявления
  - Все свои объявления с вкладками по статусам: на модерации, опубликовано,
    отклонено, заблокировано.
  - Для отклонённых показывается причина отказа; можно исправить и отправить
    повторно.
  - Редактирование и удаление объявления (вместе с фото и видео на диске).

Статистика объявления
  - Уникальные просмотры (один человек = один просмотр, повторные заходы и
    обновления страницы не накручивают), добавления в избранное, показанные
    телефоны, диалоги, график за 14 дней.
  - Не считаются: сам автор, администраторы, поисковые боты, превью ссылок.

Избранное
  - Сердечко на карточке и на странице объявления; список избранного отдельной
    страницей. Гость при нажатии отправляется на вход и возвращается обратно.

Чат
  - Диалог = объявление + покупатель. Список диалогов со счётчиками непрочитанных,
    двухпанельный интерфейс (на телефоне: список → переписка).
  - Сообщения доставляются мгновенно (свой WebSocket-сервер); если соединение
    пропало, страница показывает предупреждение, подтягивает сообщения опросом и
    сама переподключается.
  - У своих сообщений статус: «Не прочитано» / «Прочитано» (одна/две галочки, время
    прочтения во всплывающей подсказке).
  - «Печатает…», счётчик непрочитанных в шапке, нижней навигации и заголовке
    вкладки, всплывающее уведомление о новом сообщении.
  - Ограничение: до 20 сообщений в минуту.
  - Если автор выбрал «Только звонок» — начать чат по этому объявлению нельзя.

Звонки голосом и видео (WebRTC)
  - Кнопки «Позвонить» и «Видеозвонок» в шапке диалога, а на странице объявления — «Позвонить онлайн» и «Видео».
    Звонок бесплатный, без установки приложений; звонить можно прямо со страницы объявления, даже если переписки ещё нет.
  - Входящий звонок появляется поверх ЛЮБОЙ страницы сайта с рингтоном (на телефоне — с вибрацией); кнопки «Ответить»,
    «Ответить без видео», «Отклонить». Если открыто несколько вкладок или устройств, звонят все; ответившая закрывает остальные.
  - В разговоре: кнопка МИКРОФОНА (выключить/включить), кнопка КАМЕРЫ (в голосовом звонке можно включить видео, в видео — выключить),
    переключение камеры (если их несколько), «на весь экран», «свернуть» в маленькую «таблетку» сверху — разговор продолжается,
    можно листать сайт. Собеседник видит пометки «выключил микрофон» и «камера выключена».
  - ПИНГ: маленький значок вверху окна звонка — четыре «палочки» (зелёные/жёлтые/красные) и время отклика в миллисекундах.
    Клик открывает подробности: тип соединения (напрямую или через сервер), потери пакетов, джиттер, разрешение и скорость.
  - Против лагов: звук важнее картинки, у видео ограничен битрейт, при плохой сети качество видео автоматически снижается и потом
    возвращается, при обрыве сети соединение восстанавливается само, эхо- и шумоподавление микрофона включены.
  - Итог звонка попадает в переписку: «Исходящий звонок · 2:31», «Пропущенный звонок», «Звонок отклонён», «Нет ответа»,
    с кнопкой «Перезвонить». Пропущенный звонок считается непрочитанным сообщением.
  - Правила: автор выбрал «Только сообщения» — звонки выключены; «Только звонок» — чат для объявления выключен. Нельзя позвонить самому себе,
    заблокированному пользователю; не больше 6 вызовов в минуту. Блокировка пользователя администратором обрывает его звонок сразу.
  - Если прямое соединение между браузерами невозможно (мобильные сети, строгий NAT), звук и видео идут через TURN-сервер coturn.

Отзывы о продавце
  - Оценка 1–5 звёзд и текст. Оставить отзыв может только тот, кто переписывался
    с продавцом в чате (защита от накрутки). Один отзыв на продавца — повторная
    отправка обновляет его. Рейтинг считается автоматически.

Профиль и настройки
  - Имя, email, телефон, город, «о себе», аватар (автоматически обрезается и
    сжимается до 256×256).
  - Смена пароля.
  - Привязка и отвязка аккаунтов Яндекса и Google.
  - Ссылка на свой публичный профиль.

Если пользователя заблокировали
  - При попытке входа ЛЮБЫМ способом (email, Яндекс, Google) он видит красную
    плашку «Доступ ограничен» с причиной блокировки и сроком. Уже открытая сессия
    обрывается сразу.

4. ПАНЕЛЬ АДМИНИСТРАТОРА  (/admin.php)
=====================================================================================

Вход: пользователь с ролью «admin». Демо-админ: admin@example.com / admin123
(на боевом сервере пароль смените: php bin/set-password.php). Администратора
создаёт команда php bin/create-admin.php. Есть тёмная тема и мобильная версия
(боковое меню превращается в горизонтальную полосу, таблицы — в карточки).

Дашборд
  - Плитки: пользователи, объявления, на модерации, заблокировано, одобрено,
    отклонено, категории, диалоги, сообщения, состоявшиеся звонки, отзывы.
  - Графики за 14 дней: новые пользователи и объявления, сообщения в чате.
  - Очередь модерации с быстрой кнопкой «Одобрить», популярные категории,
    последние действия администраторов.

Пользователи
  - Мгновенный поиск по email, имени, телефону, номеру.
  - Фильтры: все, активные, заблокированные, администраторы, вошедшие через
    Яндекс/Google.
  - Карточка пользователя: контакты, активность, способы входа, город, IP при
    регистрации и последний IP, браузер/ОС/устройство, полный User-Agent, сколько
    ещё аккаунтов заходит с того же IP, время и версия согласия, последние входы,
    история действий администраторов, текущий бан (причина, срок, кто выдал).
  - Действия: заблокировать (с причиной и сроком), разблокировать, забанить IP,
    сменить пароль, назначить / снять права администратора, удалить пользователя
    (вместе с его фото, видео и аватаром).

Баны аккаунтов
  - Причина обязательна. Срок: навсегда, 1 день, 7 дней, 30 дней или до выбранной
    даты. Истёкшие баны снимаются автоматически.
  - Можно одновременно забанить IP-адреса пользователя (адреса администраторов и
    ваш собственный не банятся).
  - Блокировать и удалять администраторов через панель нельзя; себя — тем более.

Объявления
  - Вкладки по статусам со счётчиками, поиск, фильтры по категории, сортировка.
  - Карточка объявления: фото, видео, характеристики, способ связи, статистика,
    история модерации.
  - Одобрить / отклонить / заблокировать (с причиной), массовые действия над
    отмеченными объявлениями, удаление.

Категории и характеристики
  - Создание, переименование, удаление категорий.
  - Редактор полей характеристик: текст, число (с единицей и диапазоном), список
    вариантов, обязательность, участие в фильтрах. Новое поле сразу появляется в
    форме объявления и в фильтрах.

Отзывы
  - Просмотр и удаление отзывов.

Журнал действий
  - Кто из администраторов, что и когда сделал.

Безопасность
  - «Журнал входов»: регистрации, входы, неудачные попытки, блокировки, отказы по
    IP — с временем, пользователем, способом входа, IP и устройством; фильтры по
    IP и по типу события. Записи хранятся 180 дней.
  - «Баны по IP»: добавить бан адреса или сети (CIDR), указать причину и срок,
    выбрать область — только вход и регистрация либо весь сайт; список и снятие.
    Бан «весь сайт» не действует на администраторов с открытой сессией.
  - «Устройства и риски»: статистика браузеров, ОС и типов устройств, IP с
    большим числом неудачных попыток и несколькими аккаунтами.

Документы
  - Редактор Политики обработки персональных данных и Пользовательского соглашения.
    Простая разметка: «# Заголовок», «- пункт списка», абзацы. Подстановки:
    {{site}}, {{operator}}, {{email}}, {{date}}.
  - Вкладка «Название и контакты»: название сайта, оператор данных, контактный
    email — подставляются в шапку, подвал и документы.
  - Тексты по умолчанию — шаблоны; впишите реквизиты и проверьте их с юристом.

Интеграции
  - Статус входа через Яндекс и Google с готовыми значениями для кабинетов
    провайдеров (Redirect URI, домен) и пошаговой инструкцией.
  - Статус WebSocket, предупреждения об открытом демо-режиме и режиме отладки.

Экспорт
  - Выгрузка пользователей и объявлений в CSV (открывается в Excel, разделитель «;»,
    защита от CSV-инъекций).

5. ЗАЩИТА И ТЕХНИЧЕСКИЕ ВОЗМОЖНОСТИ
=====================================================================================

Реальный IP и устройство посетителя
  - Сайт определяет настоящий IP человека за прокси (nginx/Caddy/Docker):
    заголовок X-Forwarded-For принимается только от доверенных прокси, поддельный
    заголовок игнорируется; IPv4, IPv6 и сети (CIDR).
  - Для аналитики сохраняются IP, браузер, ОС, тип устройства и User-Agent при
    регистрации и при каждом входе. Для банов используется тот же IP.

Звонки: техническая часть
  - Сигнализация (кто кому звонит, предложение/ответ WebRTC) идёт через тот же WebSocket-сервер, что и чат; сам разговор сервер не видит
    и не записывает. TURN-сервер coturn запускается тем же docker compose; браузеры получают временные логин и пароль TURN (24 часа, подпись HMAC).
  - Заголовок Permissions-Policy: микрофон, камера и геолокация разрешены только самому сайту.
  - Чтобы собеседники не видели IP друг друга, в .env включается CALLS_RELAY_ONLY=1 (все звонки через сервер).
  - Подробности: docs/CALLS.md.

Загрузки
  - Фото: тип проверяется по содержимому, лимит 5 МБ и 25 мегапикселей,
    перекодирование (стирает EXIF и спрятанный код), случайные имена, миниатюры.
  - Видео: тип проверяется по сигнатуре файла, до 50 МБ, длительность MP4/MOV
    проверяется по заголовку (до 3 минут), отдача с поддержкой перемотки
    (HTTP Range), прикрепить можно только своё загруженное видео.
  - В папке загрузок PHP-файлы никогда не исполняются.

Общая защита
  - SQL только через подготовленные запросы; вывод экранируется (защита от XSS).
  - Права проверяются на сервере на каждом действии (владение объявлением,
    участие в диалоге, роль администратора).
  - Блокировка пользователя действует мгновенно (пользователь перечитывается из
    БД на каждый запрос).
  - Наружу смотрит только папка public/: исходники, шаблоны, миграции, .env
    недоступны по HTTP.

Поисковая оптимизация
  - robots.txt (личные страницы и API закрыты), sitemap.xml с объявлениями,
    canonical-ссылки, noindex для личных и служебных страниц, превью ссылок.

База данных и обновления
  - PostgreSQL 16; схема применяется автоматически при старте (миграции), безопасно
    при повторных запусках; база старой версии дообновляется без потери данных.
  - Обновление боевого сервера одной командой:
        cd ~/huek/avito-clone && git pull && bash bin/server-update.sh
    Скрипт обновляет код, .env, пересобирает контейнеры, настраивает nginx
    (WebSocket, лимит загрузки 64m, передача реального IP) и перезагружает его.
  - Скрипты: bin/setup-oauth.sh (ключи Яндекс/Google со скрытым вводом),
    bin/create-admin.php, bin/set-password.php.

6. ОГРАНИЧЕНИЯ (ЧТО ПОКА НЕ РЕАЛИЗОВАНО)
=====================================================================================

  - Нет восстановления пароля по email и уведомлений на почту (письма не отправляются).
  - Нет ограничения числа попыток входа и капчи.
  - Нет автоматических бэкапов базы данных.
  - Нет жалоб на объявления и пользователей кнопкой.
  - Звонок виден, только пока сайт открыт в браузере (нет push-уведомлений при закрытой вкладке); групповых звонков и записи разговоров нет.
    Звонки проверены автотестами в браузере с фейковой камерой и микрофоном и через локальный TURN; на реальных мобильных сетях и iPhone — после выкладки.
  - Нет срока жизни объявлений и автоархивации; загруженные, но не прикреплённые
    файлы остаются на диске.
  - Нет платного продвижения и оплаты.
  - Видео не сжимается и не получает кадр-превью (в образе нет ffmpeg).
  - Определение города идёт через публичный сервис OpenStreetMap Nominatim
    (около 1 запроса в секунду); для большой нагрузки нужен свой геокодер
    (переменная GEOCODER_URL).
  - Тексты политики и соглашения — шаблоны, они не заменяют юридическую консультацию.
